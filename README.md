## What I do

I build the frontend layer of products where latency, correctness and maintainability actually matter: real-time systems, typed API boundaries and shared component libraries. I set review standards and pair with design and backend teams.

| Project | What I built |
| :-- | :-- |
| **HaaNaa** <br /><sub>real-money sports prediction</sub> | Next.js dashboard for live wagering. IAM-based RBAC with a Go backend, with permission-scoped UI rendered once at session load. <br />**20K daily users · API response time ↓50%** |
| **HOAShare** <br /><sub>property & community platform</sub> | A real-time chat SDK: singleton WebSocket, Lexical rich text, voice recording, S3 pipelines. <br />**Bundle size ↓60% across 18+ components** |
| **HOAShare** <br /><sub>TypeScript layer</sub> | Standardised 40+ API boundaries with tuple-based error handling and exhaustive type guards. <br />**Adopted as the team-wide code review standard** |
| **Xamtac** <br /><sub>marketing SaaS</sub> | Next.js SaaS with SSR content generation. Turned Figma specs into an accessible React component library; reviewed 50+ PRs a month. <br />**Lead conversion +25% · downtime ↓20%** |
